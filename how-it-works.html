Overview

What this site is, and where to go

AIGroundwork is a research framework written as prompts. The framework is the set of things a careful researcher does that an AI does not do on its own: framing a question properly, chasing weak leads to sources that hold, analysing rather than summarising, testing a conclusion, and reporting it so others will read it. Written as prompts, an AI carries them out for you.

There are three ways in, depending on what you want right now.

Manual prompts

Prompts you paste into a chat to run a single research move, or a whole step, on the spot. Reach for these when you want to fix one thing in a conversation you are already in: chase a shaky figure, stress-test a conclusion, pull the channel-ready version out of a finished report.

Run it on everything

System prompt

The whole framework as one standing instruction for a project or an agent. Install it once and every research task gets the full process without being asked. Use this when research is ongoing work, not a one-off.

Get the system prompt

The manual prompts and the system prompt are the same framework at two scales: one move at a time in a chat, or the whole thing running standing. How it works explains the framework behind both. For the case for why these beat an ordinary prompt, see the home page.

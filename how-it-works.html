How it works

An ordinary prompt does what you ask. These do what a researcher would.

A capable prompt already gets you a plausible answer. Ask an AI to assess a vendor's claim of 40 enterprise customers, and tell it to check each named customer against their own filings, and it will. Good prompting produces good work. The limit is that a prompt only does what you thought to ask for, and the most valuable parts of research are the ones that decide what to look at in the first place. You cannot ask for those, because asking would mean you already had the answer.

That is the difference these prompts make. Each one carries a method a careful researcher uses: reframing a question that was put badly, chasing a weak lead to a source that holds, laying two things side by side to see what the comparison reveals, searching for the evidence that would prove a conclusion wrong. An ordinary prompt does none of these unless you spell them out every time. A prompt that carries the method does them because the method is built in.

You use the method at whatever scale the work needs. A single method-prompt runs one move in a chat. The system prompt runs the whole method standing, in a project or an agent, so every research task gets the full process without being asked.

01
What a plain prompt cannot reach

You set the topic and handed it over. So the AI will not stop and tell you the question worth researching is slightly different from the one you asked.

You can only name leads you already know about. So the small detail that quietly changes the answer, the one you did not know was there, gets missed.

You would have to have already spotted the useful comparison for the AI to lay two things side by side and show you what it reveals.

The method covers these because it does not wait to be asked. That is what a careful researcher does by habit, written down so the AI follows it.

02
Bedrock / holds throughout

Standards that run under every step

ST-1Rank the sourcesPrimary and institutional sources support a fact; weak sources only point to leads.
ST-2Match effort to stakesBackground gets one source; a load-bearing claim gets the full chase and the contrary search.
ST-3Keep a running recordEvery claim that matters, its status, its best source, what was searched.
ST-4RevisitA finding that undoes earlier work sends the task back to the step it affects.
03
What it does not do / honest limits

It raises the floor, not to certainty. The method makes a sound result far more likely. It does not guarantee one. The same prompt will occasionally miss a lead it usually catches, which is why it is worth checking one once whenever you change it.

It costs more. The full method might run ten searches on a task a bare request would answer in two. Matching effort to stakes is what keeps that work aimed at the claims that actually carry the conclusion.
